# NEON WhatsApp AI Bot CRM

A focused three-page Next.js app for NEON TOURISM FZE.

## Pages

- WhatsApp AI Bot: service dropdown, guided questions for name, phone, and email, validation, and automatic CRM save.
- CRM: searchable lead table with editable lead status.
- Dashboard: total leads, today's leads, conversion, contacted leads, and popular services.

## Run Locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

The app is configured as a static Next export and publishes from `out` on Netlify.
